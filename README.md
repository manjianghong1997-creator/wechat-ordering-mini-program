# 微信扫码点单小程序

一个基于微信小程序原生开发和微信云开发的扫码点单演示项目，适合餐饮门店的扫码点餐、订单管理和销售统计场景。

## 已完成功能

- 顾客扫码点单入口
- 商品分类展示
- 商品列表展示
- 购物车加减商品
- 提交订单
- 订单成功页
- 商家订单管理
- 订单状态更新
- 销售统计
- 桌号管理
- 模拟扫码桌号参数
- 商品管理
- 分类管理
- 微信云数据库接入

## 技术栈

- 前端：微信小程序原生开发
- 后端：微信云开发 CloudBase
- 数据库：微信云数据库
- 版本管理：Git / GitHub

## 云数据库集合

项目当前使用以下集合：

- `orders`：订单数据
- `tables`：桌号数据
- `categories`：分类和商品菜单数据
- `cloud_tests`：云开发连接测试数据

## 本地运行

1. 打开微信开发者工具。
2. 导入本项目目录。
3. 填写自己的小程序 AppID。
4. 开通微信云开发环境。
5. 在 `app.js` 中配置自己的云环境 ID。
6. 在云数据库中创建需要的集合。
7. 点击编译运行。

## 当前云环境配置位置

云环境 ID 配置在：

```js
// app.js
cloudEnv: 'cloud1-d9gz14l27a9a3b381'
```

如果换成自己的小程序，需要把这里替换成自己的云环境 ID。
